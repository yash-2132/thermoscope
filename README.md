# THERMOSCOPE

Repository: https://github.com/yash-2132/thermoscope · Website (after enabling GitHub Pages): https://yash-2132.github.io/thermoscope/

**Research question.** Can regularised regression and kernel methods accurately predict thermodynamic residual
properties and classify fluid phases across a generalised reduced space?

## Abstract

One observation is one pure chemical species at one thermodynamic state, described by reduced temperature
`Tr = T/Tc`, reduced pressure `Pr = P/Pc` and acentric factor `omega`. Polynomial OLS, Ridge and Lasso
regressions predict the compressibility factor `Z` and four dimensionless residual properties; multinomial
logistic regression and an RBF support vector machine predict the phase (vapour, liquid, supercritical).
Whole fluids are held out for testing. The regressions reproduce the smooth single-phase behaviour but not the
discontinuity at saturation (Z: test R² 0.870); for the continuous fugacity coefficient
the same model reaches R² 0.988. Regularisation fixes conditioning rather than accuracy. The
RBF-SVM classifies phases with macro-F1 0.997 on unseen fluids against 0.837 for logistic
regression. Extrapolation beyond the training range of `omega` fails.

> **Important: reference data in this build.** The published results use the **Peng-Robinson equation of
> state** (`--backend pr`), not CoolProp. CoolProp could not be installed in the environment where the pipeline
> was run. A CoolProp backend is implemented in `src/thermoscope/dataset.py` but **has not been executed**;
> run it locally (below) and treat its first run as a test. The website also evaluates the Peng-Robinson
> reference live in the browser for its surfaces, so after switching the dataset to CoolProp those live reference
> surfaces would no longer match the dataset until reference grids are exported (listed under future work).

## Dataset

- Source: Peng-Robinson (1976), thermoscope.eos_pr. Seed 20261115.
- 22 fluids, 10340 states requested, **10308 valid observations**.
- Sampling per fluid: `Tr` uniform on [0.6, 1.6]; `ln Pr` uniform with `Pr` on [0.03, 3].
- Rejected: {'saturation_guard': 32, 'invalid_state': 0, 'ambiguous_phase': 0, 'backend_error': 0}; duplicates removed: 0; missing values: 0.
- States with `|ln(Pr/Psat)| < 0.02` are excluded (saturation guard band; sensitivity in `outputs/ablations.json`).
- Access: `outputs/dataset.csv` (also `docs/data/dataset.csv`), regenerated by the command below.

### Data dictionary

| Column | Meaning |
|---|---|
| `fluid`, `fluid_id` | Species (grouping only, never a model input) |
| `Tr`, `Pr`, `omega` | Features: reduced temperature, reduced pressure, acentric factor |
| `Z` | Compressibility factor |
| `ar`, `hr`, `sr`, `gr` | Residual Helmholtz energy / RT, enthalpy / RT, entropy / R, Gibbs energy / RT |
| `lnphi` | Fugacity coefficient, `gr - ln Z` (extra target) |
| `phase` | 0 vapour (CoolProp gas), 1 liquid, 2 supercritical (supercritical, supercritical_gas, supercritical_liquid) |
| `split`, `cv_fold` | `train`/`test` by fluid; fold 0-4 for training rows, -1 for test rows |

Residual = real fluid minus ideal gas at the same temperature and molar density (CoolProp convention).

## Preprocessing

Fixed physical transforms (reduced coordinates, division by RT or R, `ln Pr` for classifiers, polynomial
expansion) use no data statistics. The only learned transform is standardisation, which sits inside a
scikit-learn `Pipeline` and is therefore fitted on training folds only. No resampling for class imbalance;
macro-F1 and balanced accuracy are reported.

## Evaluation methodology

- Primary: 80/20 split **by fluid** (`GroupShuffleSplit`, seed 20261115). Test fluids: Methane, n-Hexane, Ethylene, Water, Hydrogen sulfide.
- Model selection: 5-fold `GroupKFold` inside the training fluids (`outputs/splits.json`).
- Search: degree 1-5; Ridge 19 penalties 1e-6..1e3; Lasso 10 penalties 1e-5..1e-2; logistic C in
  {0.1, 1, 10, 100, 1000}; SVM C in {1, 10, 100, 1000} x gamma in {0.1, 0.3, 1, 3, 10}.
- The test fluids are used once, for final reporting. Group separation is asserted in code and tests.
- Secondary (kept separate): row-wise 80/20 split; extrapolation in omega; guard-band sensitivity.

## Models

Mean predictor and degree-1 linear regression (baselines), OLS / Ridge / Lasso on degree-5 polynomial
features; majority class (baseline), multinomial logistic regression, RBF-SVM (Platt scaling where a
probability is needed).

## Setup and reproduction

```
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
export PYTHONPATH=src
python -m thermoscope.run --backend pr --repo-url https://github.com/yash-2132/thermoscope   # ~20 min; writes outputs/ and docs/data/
pytest -q                                                                            # 11 checks
jupyter notebook notebooks/                                                          # run both notebooks top to bottom
python -m http.server -d docs 8000                                                   # website at http://localhost:8000
```

CoolProp backend (untested here): `pip install CoolProp` then `python -m thermoscope.run --backend coolprop`.
Both notebooks are saved with their outputs and only read files in `outputs/`, so they can be viewed on GitHub without running anything.
The website needs no build step.
